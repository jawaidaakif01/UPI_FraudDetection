⛨ FraudGuard AI
Empowering secure digital transactions through intelligent fraud detection.

FraudGuard AI is a comprehensive security suite designed to protect users from the rising tide of UPI scams, phishing messages, and fraudulent payment requests. Built with a modern, "curvy" UI/UX, it provides real-time analysis for safer digital banking.

🚀 Features:-
⚡ Analyze Payment: AI-driven risk assessment for transactions based on banks, amounts, and receiver history.

🔗 UPI ID Check: Scans VPA handles (e.g., name@upi) against known scam patterns and blocklists.

💬 Message Check: Uses NLP (Natural Language Processing) patterns to identify phishing links and urgent "spam" language in SMS or emails.

🚩 Community Reporting: Allows users to report new scams, contributing to a global shared security database.

🛡️ Admin Control: A dedicated dashboard for administrators to review reports and manage the global blacklist.
